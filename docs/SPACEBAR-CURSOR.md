# 空白鍵滑動游標

自 v1.2.0 起包含在正式版 APK。

## 使用方式

1. 長按空白鍵，等待震動與空白鍵上的「← →」提示。
2. 保持按住並左右滑動，移動文字游標；放開後恢復一般輸入。
3. 短按仍維持原本的空白／一聲／候選切換功能。

等待時間遵循 Android 系統長按設定，滑動每 12 dp 移動一個字元邊界。
長按後不滑動不會輸入空白，也不會提交組字。
首次移動前會先送出目前已確定的候選；無完整候選時保留原始注音。
若輸入框拒絕組字提交，就不移動游標。
長按觸發前先滑動，只會取消長按；若在空白鍵上放開仍視為短按輸入空白。
空白鍵未放開就按下一個鍵時，會先送出空白再處理下一個鍵。
取消觸控、長按啟動後的多指操作、隱藏鍵盤或切換輸入框會取消手勢。

## 驗證（2026-10-03）

- 84 項 JVM 測試通過，包括短按、長按、左右反向、微小抖動與取消。
- Samsung SM-S9280 / Android 16：7 項指定裝置測試通過。
  包括中文、家庭 emoji、組合字元、選取範圍、游標邊界、方向鍵備援、
  實際空白鍵觸控範圍／長按計時器，以及原有中英文頁切換。
- 真正 IME + debug 測試輸入框：`abcdef` 游標由 6 → 3 → 5，文字不變；
  組字中的 `abcdeㄅf` 完整保留，游標由 6 → 5；接著切英文輸入 `q` 和短按空白，
  得到 `abcdeq ㄅf`，證明沒有重複組字或遺失游標位置。
- Debug APK、測試 APK 與 lint 完成；lint 0 errors、31 warnings。
- 尚未驗證其他廠牌、舊版 Android、RTL 文字與各種第三方自訂輸入框；
  實機震動手感仍需使用者確認。

一般輸入框使用 Android ICU 字元邊界與 `InputConnection.setSelection`。
無法提供文字快照或不支援選取操作的輸入框，改送成對的左右方向鍵事件。
僅在記憶體處理目前輸入框文字，不新增文字紀錄或網路傳輸。
