# 使用回饋功能

自 v1.2.0 起包含在正式版 APK。

## 操作方式

- 頂部只有一排：閒置時顯示全／半形、Emoji、剪貼簿、設定；開始輸入注音後，同一位置換成候選字。高度不變，按鍵不會跟著移動。
- 選定中文候選後，同一排提供常見下一詞與本機學習的接續詞。例如「我」之後提示「想、是、要、的」，「生日」之後提示「快樂」。
- 預測出現時，第一次退格只收起預測並恢復工具列，不刪字；這一次即使繼續長按也不連刪。放開再按才正常刪字。組字中的退格維持刪除注音。
- 選過的相鄰中文候選詞可學習，常用接續詞往前排。這是小型離線功能，並非完整語境或雲端預測；沒有合適提示時恢復工具列。標點可由符號頁輸入。
- 中文 `123`／`#+=` 頁使用全形標點，包含「」『』【】。數字仍為 0–9；工具列「全形／半形」顯示目前符號模式，點擊切換。英文及數字專用欄位使用半形。
- 工具列「😊」打開常用 Emoji，按「返回」回到原頁；按「注」也可直接返回注音。
- 「剪貼簿」開啟獨立可捲動面板，點紀錄貼上；可釘選、取消釘選、單筆刪除、清除未釘選及返回鍵盤。「儲存歷史」預設關閉，開啟後開始收錄；關閉只停止新增。
- 未釘選最多 50 筆，超過 1 小時者於存取及面板開啟期間清理（不使用剪貼簿時不會主動刪除）。釘選最多 50 筆，不因到期或容量上限被清除；滿額會提示。取消釘選後重新計算 1 小時。資料保存於本機，程序重啟仍保留；解除安裝／清除 App 資料會全部刪除。
- 「設定」開啟與輸入法相同 Android 使用者設定檔的設定頁。點「鍵盤高度與外觀」展開高度、間距、下方留白、按鍵比例、候選列高度及字體大小。
- 調整自動保存；試打框可立即查看，Pixel／iOS 預設會同步更新滑桿。下方留白會把按鍵往上移。空間不足時按比例縮小垂直尺寸，保留至少約三成高度給輸入區；儲存的設定值不變。
- 長按空白再左右滑動移動游標，詳見 [空白鍵滑動游標](SPACEBAR-CURSOR.md)。

## 學習與限制

下一詞只根據本次輸入中實際選定的中文詞，以及緊接著選定的詞；不掃描其他應用程式歷史內容。英文、Emoji、標點、空白、貼上及切換輸入欄位不建立接續詞紀錄。移動游標後不符合前詞位置的提示會取消。

「暫停學習」停止新增，既有紀錄仍可使用；「清除學習紀錄」同時清除候選排序與下一詞紀錄。一般匯出不含學習資料，只有明確選擇包含學習紀錄的備份才包含這些詞對。密碼及禁止個人化學習的欄位不記錄、不套用個人化候選；密碼／Email／ASCII／數字欄位不顯示 Emoji 或貼上工具。

Emoji 目前為常用選單，沒有搜尋、膚色選擇或最近使用清單。符號使用獨立頁與全／半形切換，未加入長按符號選單。

剪貼簿只存純文字，忽略敏感標記、空白及超過 20,000 個 UTF-16 單位的內容；密碼／禁止個人化欄位不收錄、不開啟歷史面板。不能辨認所有敏感內容，也無法找回功能啟用前或程序停止期間被覆蓋的紀錄。歷史不納入字典匯出或候選學習。「貼上目前內容」不需啟用歷史。記憶體不足不等於自動清除持久資料，因此由本功能管理保留期限及筆數。

## 驗證範圍（2026-10-04）

- Android Studio 啟動的 CodexZhuyin111 模擬器，Android 16 / API 36.1。
- 86 項 JVM 測試、21 項 Android instrumentation 測試通過；涵蓋實際 Canvas 按鍵觸控、英文往返、空白長按、游標字元邊界、版面預設同步、短螢幕邊界，以及 SQLite 下一詞紀錄的隔離、匯出、清除與重新匯入。另驗證工具／候選／預測互斥且鍵位不變，以及首次退格取消預測後持續按住不啟動連刪。
- 新增 4 項 Android SQLite 剪貼簿測試：假時鐘驗證期限及取消釘選後重新計時、50 筆一般／50 筆釘選上限、釘選持久化與重複內容合併、刪除後不重新收錄同一份系統剪貼簿、敏感／空白／超長內容排除。
- 模擬器真實操作：複製 `clip_one` 並釘選，再複製 `clip_two`；覆蓋安裝重啟後釘選仍在。「清除未釘選」保留 `clip_one`，點該紀錄成功貼上。關閉歷史後複製 `clip_off`，重新開啟面板沒有新增該紀錄，原釘選仍在。面板「返回」可回到鍵盤。
- 真正 IME 與測試輸入框：`ㄨㄛˇ` → 選「我」→ 提示「想、是、要、的」；選「要」後再次輸入「我」，「要」排到第一。
- 單列切換實測：選「我」後長按退格 1.2 秒，文字與游標維持「我」／1，頂部恢復工具列；放開再按才刪除「我」。再次組字 `ㄨㄛˇ` 時，退格正常刪成 `ㄨㄛ`，候選列仍顯示。
- 實際按鍵輸入 `「」【】『』`，切半形輸入 `?`，再插入 `😀❤️`。複製測試字串後按工具列「貼上」，輸入框得到完全相同的第二份字串。
- 設定頁實際滑桿由按鍵高度 47 調至 70，下方留白由 0 調至 28.9；SharedPreferences 與可見鍵盤均同步改變。
- 2400 × 1080 橫向畫面以高度 70／下方留白 28.9 輸入 `ㄨ`，確認輸入框、候選列與底排控制鍵同時可見。
- 編譯與 lint 完成，lint 0 errors、39 warnings（包含原有風格／國際化建議）。最後僅調整面板開關位置，另完成編譯、lint 與上述面板操作驗證。

本批只安裝在模擬器，尚未裝入手機或發布。其他廠牌、舊版 Android、第三方特殊輸入框、螢幕閱讀器，以及完整橫豎向／字體縮放組合仍需後續驗證。
